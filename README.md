# NeuralBandit

Columbia COMS4726 Final Project - Implementation and "Improvement" of Neuralbandit algortihm, from “A Neural Networks Committee for the Contextual Bandit Problem” Robin Allesiardo · Raphaël Féraud · Djallel Bouneffouf





Running Information:



Quick test (Original):

&#x09;python neuralbandit3\_original.py --steps 2000 --models small



Longer run (Original):

&#x09;python neuralbandit3\_original.py --steps 50000 --models small



Concept-drift test (Original):

&#x09;python neuralbandit3\_original.py --steps 6000 --models small --drift-every 2000 --log-every 100 --rolling-window 200
